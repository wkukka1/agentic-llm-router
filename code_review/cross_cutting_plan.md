## Priority 4 — agentic/execution scaffolding

**Status 2026-09-15: done.** Full plan (context, exact approach) is in the session's plan file; summary below. Fixed in source (all tests pass, 529/529; import-linter 3/3 contracts kept).

Two Explore agents re-verified all seven findings fresh (none touched by Priorities 1-3). Key finding: XA-07, XA-08, XD-12, XD-13, XD-14 all trace to one thing — `router.execution.*` (`Orchestrator`/`AgentTask`/`ExecutionResult`/`BudgetLedger`), `router.llm.client.*` + adapters, `router.tracing.ExecutionTrace`, and `router.tools.RouterTool` + `router.context.RoutingMode.MODEL_SELECTION` are a more elaborate "production" agentic design drafted alongside the live `router.agentic.AgenticRouter` but never wired to it — confirmed **fully dead** (zero production callers anywhere; `Orchestrator.can_spawn`/`spawn` aren't exercised by a single test).
